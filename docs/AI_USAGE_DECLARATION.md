# AI usage declaration

The Last Current is an English-language Godot project about a ship navigating a fictional archipelago. ChatGPT/Codex assisted with the concept, GDScript structure, navigation algorithms, interface, Python reference and documentation. The team requested an assessment against the AI Fundamentals requirements and preparation of the source package for submission.

During package preparation, Codex made the one-step weather transition assumption explicit in GDScript and Python, aligned the simulated storm draws with the stated priors, prepared numerical examples and added a Godot career test. The Python reference, unit suite and automated game scenario were run during AI-assisted verification. The test report describes how to repeat these checks. They are recorded as automated checks.

The maps, observation probabilities and rewards are synthetic. The report identifies these assumptions and the limits of the simulation. Each student is responsible for explaining the submitted algorithms and identifying their own contribution during the defense.
